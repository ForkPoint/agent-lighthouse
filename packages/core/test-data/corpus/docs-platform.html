API Authentication & Endpoints

CloudStack provides secure token-based authentication for both human developers and autonomous AI agents.

What is CloudStack API Authentication?

Authentication is the verification process used by CloudStack to confirm the identity of an API client using asymmetric cryptographic keys or scoped Bearer tokens.

Step-by-Step Integration Guide

  1. Generate an API secret key in your dashboard under Settings > API Keys.
  2. Pass the token in the Authorization: Bearer <TOKEN> header on every HTTP request.
  3. For Model Context Protocol (MCP) integrations, configure your client using .well-known/mcp.json.
curl -X GET https://api.cloudstack.dev/v1/clusters \
  -H "Authorization: Bearer cs_live_abcdef123456" \
  -H "Accept: application/json"
