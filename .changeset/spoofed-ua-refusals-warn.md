A refusal of a spoofed bot User-Agent now warns instead of failing. The scanner sends each bot's User-Agent from its own address, so it is never the verified bot, and Cloudflare (its "Challenge bad bots" example rules, Super Bot Fight Mode) and Anubis document rules that refuse unverified traffic while admitting the verified bot. Answers that say something about the site, whoever asks, still fail.

- `access-crawl-control/ai-crawler-edge-parity`: a Cloudflare challenge, a proof-of-work wall, a 200 challenge page and any non-2xx where a browser got 200 now warn, like an opaque 403 already did. A pay-per-crawl 402 with a price and a soft block with no challenge in it still fail. A challenge marker counts only when the browser page does not carry it too, so an Akamai or Imperva script on the normal page no longer turns a real soft block into a challenge.
- `agentic-commerce/agent-ua-commerce-parity`: a challenge marker, a 403, 429 or 503 and any other non-2xx now warn at Medium instead of failing at Critical. This matches edge parity. A stub page, a priced 402 and a robots.txt disallow still fail. An Anubis page served with HTTP 200 now reads as a challenge, as in edge parity, through one shared classifier. An Akamai or Imperva storefront whose normal page carries their script no longer reads as a challenge on every probe. The homepage is probed once, and the two sampled pages are the next two scanned pages, so a second product page is now sampled.
- `agentic-commerce/cart-handoff-reachability`: a 403 or 429 to the ChatGPT-User request, and a challenge page or widget served only to it while a browser gets the cart, now warn. A ChatGPT-User refusal is compared only where the browser got a 2xx. A wall the browser gets too still fails, and its message now counts any agent-only findings beside it.
- `access-crawl-control/bot-content-delta-declared`: a reduced page now triggers one control fetch as an unrecognised bot. If the control bot gets the same reduced page as the crawler request (checked against the crawler's page, not only the browser's), the delta is bot management and warns. A delta keyed on the crawler's name, a control that got some other reduction, and a declared selector that matches nothing still fail. A thin 200 carrying a challenge marker is no longer compared.

Dossiers are updated with the sources, verified 2026-10-20. No id, tier, grade, weight or schema changed.
