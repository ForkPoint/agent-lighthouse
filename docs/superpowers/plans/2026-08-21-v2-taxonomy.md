# v2 Taxonomy Restructure Implementation Plan (Plan 3 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every surviving audit into the 8 agent-journey categories with `category/slug` ids, evidence-graded tiers, and dossier linkage; execute the 8 approved sunsets; rebuild category scoring on evidence mass.

**Architecture:** Data-driven restructure. The single source of truth for every move is `docs/evidence/v2-audit-map.md` (189 rows, user-approved 2026-08-21); tier/weight derive from each audit's dossier `evidence_grade`. Audits move file-by-file into `packages/core/src/audits/<v2-category>/`; the registry becomes 8 per-category `index.ts` registries; numeric ids die; `migration-map.json` records every rename. Merges/splits/rewrites are NOT executed here (Plan 4) — merge-away audits move with temporary slugs and `TODO(merge)` markers.

**Tech Stack:** TypeScript, zod, vitest, changesets. Branch: continue on `feat/v2-engine`.

**Spec:** `docs/superpowers/specs/2026-08-21-audit-restructure-design.md` §3 (categories), §4 (tiers/weights/evidence-mass), §6 (layout, ids, meta fields, CI linkage). Data: `docs/evidence/v2-audit-map.md` (map), dossier frontmatter `evidence_grade` (grades).

## Global Constraints

- Tests from REPO ROOT: `pnpm test <path>`; full `pnpm test` must end 0 failures. Never `pnpm --filter ... test -- run`.

- One audit = one file (project memory). Do NOT split `_a11y.ts` in this plan (Plan 4); it moves whole to `operability-safety/` and its per-rule audits keep registering from it.
- Dossier moves mirror audit moves: `docs/evidence/audits/<v1-cat>/<slug>.md` → `docs/evidence/audits/<v2-cat>/<v2-slug>.md` via `git mv`, frontmatter `category:`/`slug:` updated. Sunset dossiers go to `docs/evidence/sunset/` instead.

### Task 1: v2 meta contract — evidenceGrade, tier, dossier, slug ids

**Files:**
- Modify: `packages/core/src/types.ts`, `packages/core/src/schemas.ts`, `packages/core/src/audit.ts`, `packages/core/src/audit-runner.ts`
- Test: `packages/core/src/v2-meta.test.ts` (new)

**Interfaces (produced, all later tasks consume):**

```typescript
export type EvidenceGrade = 'A' | 'B' | 'C' | 'D';
export type AuditTier = 'scored' | 'informative' | 'experimental';
/** Spec §4 weight law. */
export function weightForGrade(grade: EvidenceGrade, tier: AuditTier): number {
  if (tier !== 'scored') return 0;
  return grade === 'A' ? 1.0 : grade === 'B' ? 0.6 : 0;
}
```

`AuditMeta` gains REQUIRED fields (this breaks every existing audit meta until Tasks 3–10 stamp them — the schema stays permissive until Task 11 flips enforcement):

```typescript
  /** Evidence grade from the audit's dossier (docs/evidence/POLICY.md). */
  evidenceGrade?: EvidenceGrade;   // optional in Task 1; Task 11 makes schema require it
  /** Scoring tier derived from the grade (spec §4). */
  tier?: AuditTier;
  /** Repo-relative path to the audit's evidence dossier. */
  dossier?: string;
```
